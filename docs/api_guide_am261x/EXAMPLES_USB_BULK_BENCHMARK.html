Introduction

This benchmark measures USB High-Speed bulk transfer performance using a custom vendor class driver that optimizes for maximum throughput. It tests device-to-host (IN), host-to-device (OUT), and bidirectional transfer modes.

Key Features:

  • Custom vendor class driver with 16 KB buffer transfers
  • Bypasses TinyUSB FIFO limitations for optimal performance
  • Measures sustained throughput in three modes: TX, RX, and bidirectional

Building benchmark application

make -s -C examples/benchmarks/usb/usb_bulk_benchmark/am261x-lp/r5fss0-0_freertos/ti-arm-clang/

Running benchmark application

  1. Build and run the application on AM261x board
  2. Connect the board to a host PC via USB
  3. Run the host test script:
python3 tools/usb_test_scripts/usb_bulk_benchmark_host.py --mode in --duration 10
python3 tools/usb_test_scripts/usb_bulk_benchmark_host.py --mode out --duration 10
python3 tools/usb_test_scripts/usb_bulk_benchmark_host.py --mode bidir --duration 10
