Introduction

This section provides performance measurements for USB benchmarking examples on AM261x using TinyUSB stack. The benchmarks measure bulk transfer and different throughput for different data directions and operating modes to characterize USB High-Speed performance on the platform.

Benchmarking Examples

The MCU+ SDK includes the following USB benchmarking examples:

USB Bulk Transfer Performance

Performance Results

Test Configuration:

  • Transfer size: 16 KB buffers
  • Duration: 10 seconds per test
  • Packet Loss: 0% (all modes)
Test Mode Throughput CPU Load Notes
TX (Device→Host) 39.31 MB/s 7.19% Single direction send
RX (Host→Device) 36.41 MB/s 9.96% Single direction receive
Bidirectional 37.71 MB/s 8.77% Sequential transfers (TX then RX)

Notes:

  • Theoretical maximum throughput: ~60 MB/s (USB 2.0 High-Speed)
  • Bidirectional mode uses sequential transfers (device sends first, then host sends)

Performance Results

Test Mode Throughput CPU Load Notes

RX (Host→Device) 36.20 MB/s ~10.3% Using TinyUSB vendor class
Bidirectional 29.33 MB/s ~28.1% Sequential transfers (TX then RX)

Notes:

  • TinyUSB vendor class uses standard FIFO-based transfers
  • Performance differs from custom vendor class due to different buffer management strategies

USB DFU Performance

DFU (Device Firmware Upgrade) class for firmware updates over USB.

Performance Results

Test Mode Throughput CPU Load Notes
Upload (Device→Host) 2.16 MB/s 52.92% Firmware upload from device
Download (Host→Device) 1.62 MB/s 51.78% Firmware download to device

Notes:

  • Lower performance compared to bulk transfers due to protocol overhead
  • Suitable for firmware update scenarios where speed is not critical
