Introduction

This benchmark measures USB High-Speed performance using TinyUSB's built-in vendor class driver. It serves as an alternative implementation to compare against the custom vendor class driver used in the USB Bulk Benchmark.

Key Features:

  • TinyUSB vendor class driver implementation
  • Standard TinyUSB FIFO-based transfers
  • Measures sustained throughput in multiple modes

Building benchmark application

make -s -C examples/benchmarks/usb/usb_vendor_benchmark/am261x-lp/r5fss0-0_freertos/ti-arm-clang/

Running benchmark application

  1. Build and run the application on AM261x board
  2. Connect the board to a host PC via USB
  3. Run the host test script:
python3 tools/usb_test_scripts/usb_bulk_benchmark_host.py --mode in --duration 10
python3 tools/usb_test_scripts/usb_bulk_benchmark_host.py --mode out --duration 10
python3 tools/usb_test_scripts/usb_bulk_benchmark_host.py --mode bidir --duration 10
